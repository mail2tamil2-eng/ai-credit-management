•	Clicking the “Create Course” icon shall display a pop-up with two options: “Blank Course” and “AI Course Generator.”
•	Access to the “AI Course Generator” option shall be restricted to users with the Administrator role just like course creation. 
•	The AI Course Generator option shall be visible and enabled only if the required AI API keys are configured for the tenant. Otherwise, the option shall remain hidden or disabled.
•	Selecting “AI Course Generator” shall display a form with the following fields:


Field Name	Mandatory?	Description / Validation Rule
Course Name	Optional	Free text. If left blank, the Course Name will be generated by ai
Course Category	Mandatory	Dropdown listing all available course categories retrieved from the LMS.
Source Text	Conditional*	Multi-line text area for pasted/entered source content. An “Enhance with AI” button shall be available to refine the entered text. 2000 — character limit (If the entered text exceeds the maximum character limit, the character count shall be displayed in red, along with the validation message: "Character limit exceeded.")

Course Audience	Optional	Free text describing the intended target audience.
Teaching Goals	Mandatory	Multi-line text area for learning objectives. An “Enhance with AI” button shall be available. Select Language	Mandatory	Dropdown of supported languages for generated content. The Default Selection can be English.

*At least one of Source Text or Upload File is mandatory
•	The system shall validate that at least one of Source Text or Upload File is provided. If neither is provided, the “Generate Course” button shall remain disabled and a validation message shall be displayed. 
Error Message: Please provide either Source Text or upload a supporting document to generate the course.
•	If both Source Text and an uploaded file are provided, the AI engine shall use content from both sources when generating the course.
•	The “Enhance with AI” button on the Source Text field shall send the current text to the AI engine and return improved/expanded content into the field.
•	The “Enhance with AI” button on the Course Objectives field shall send the current objectives to the AI engine and return improved/expanded content into the field.
•	If any mandatory field is missed, system must display an error message: This Field is required. 
4.2	Course Topic Display
Once the Generate Course button is clicked, the AI will generate the course topics and display each topic along with a brief preview of its content. Users will also have the option to regenerate/delete individual topics if required. The course must follow the default structure below. This structure should be configurable through the backend:
Course Overview
Topic 1 
Topic 1 Overview
Topic 1 content 
Topic 1 content cont..
Recap/Summary
Knowledge check
Topic 2
Topic 3
Final Exam/Quiz
Course Feedback
Note: 
	If the user does not specify the number of topics, the system must default to generating 3 (overview, content, summary) topics.
	The number of quiz questions within the topic can be defaulted to 3.
The Final Quiz and Feedback activities must also be displayed as separate topics at the end of the course. Each should display the configured number of questions. 
This Section must have generate and publish Button. 
4.3	Course Generation Process
•	Clicking “Generate Course” shall trigger AI-based generation using all provided form inputs
•	The system shall display a progress indicator while course generation is in progress.
•	Upon successful generation, the system shall display the generated course topics within the standard Moodle course structure.
4.4	Publish Workflow.
•	Once published, the course shall behave as a standard Moodle course, subject to standard course visibility and enrolment settings.
4.5	Default Course Settings
•	The system shall auto-generate the Course Thumbnail, Course Description using AI, based on the generated course content.
•	The system shall auto-generate the Course Short Name using AI.
•	The system shall set the Course Start Date to the date on which the course is created.
•	The system shall set the Course End Date to “None” by default.
•	All other course settings not explicitly listed shall default to the standard Moodle course default settings configured in the LMS.
