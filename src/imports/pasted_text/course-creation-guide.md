4.2	Course Topic Display
Once the Continue button is clicked the ai will generate topics and will display the topics with the option to edit the topic or add more topic“
The below message must be displayed on top of the UI.
The generated outline serves as the structure of your course. You can edit or delete any topic, add new topics, and insert quizzes wherever needed. Don't worry—you'll also be able to make further changes in the next step before finalizing your course.
Each generated topic (is a page activity) must display its relevant subtopics and provide an option to add a quiz at the topic level. When adding a quiz, the user should be able to specify the number of quiz questions.
Additionally, the page must provide options to add a Final Quiz and a Feedback activity at the end of the course. Users should also be able to specify the number of questions for the Final Quiz.
The Page must have a generate course button. 
Note: By default, each topic must contain two Page activities. This default configuration should be managed through the backend and should not require manual setup by the user.
4.3	Course Generation Process
•	Clicking “Generate Course” shall trigger AI-based generation using all provided form inputs
•	The system shall display a progress indicator while course generation is in progress.
•	Upon successful generation, the system shall display the generated course topics within the standard Moodle course structure.
•	If generation fails, the system shall display an error message and preserve all entered form data so the Administrator can retry without re-entering information. Error Message: "Course generation failed. We couldn't generate the course at this time. Please try again.
4.4	Generated Course Management 
•	The system shall allow the Administrator to add/ generate a new topic or activity the generated course.
•	The system shall allow the Administrator to regenerate an individual image within the course.
•	The system shall allow the Administrator to regenerate an individual Topic or Activity. 
•	The system shall allow the Administrator to edit or delete an individual image, text, topic, or activity.
•	Any regenerate, edit, or delete action performed on one course item shall not alter or remove any other section, lesson, activity, or image in the course.
•	The System shall allow reordering of topics/activities. 
4.5	Publish Workflow
•	A “Publish” button shall be displayed once course generation is complete and shall remain available while the course is in draft/unpublished state.
•	Clicking “Publish” shall publish the course under the Course Category selected during generation.
•	Once published, the course shall behave as a standard Moodle course, subject to standard course visibility and enrolment settings.
4.6	Default Course Settings
•	The system shall auto-generate the Course Thumbnail, Course Description using AI, based on the generated course content.
•	The system shall auto-generate the Course Short Name using AI.
•	The system shall set the Course Start Date to the date on which the course is created.
•	The system shall set the Course End Date to “None” by default.
•	All other course settings not explicitly listed shall default to the standard Moodle course default settings configured in the LMS.
